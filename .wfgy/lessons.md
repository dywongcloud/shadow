Generalizes to: An untagged (`__untagged__`) project with no deployments and no relational rows is a known dead-end this platform's own tenancy-reconcile loop cannot repair (it can only ADD a tag it can infer from existing deployment/relational data -- nothing to infer here) and, before this fix, had NO manual repair path either.
